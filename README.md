# Portfolio

Site portfolio personnel développé avec React et TypeScript.

## Stack technique

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lenis (smooth scroll)

Le projet inclut un piano interactif dans la section profil.

## Installation

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
